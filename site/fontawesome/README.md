# Local Font Awesome

This directory is intended to host a local copy of Font Awesome 6.4.0.

The `css/all.min.css` file contains `@font-face` declarations that expect
webfont files in the `webfonts/` subdirectory:

- `fa-solid-900.woff2`
- `fa-regular-400.woff2`
- `fa-brands-400.woff2`

Due to environment restrictions, the actual font files are not included.
Download them from the official Font Awesome distribution and place them in
`webfonts/` for icons to render correctly.
