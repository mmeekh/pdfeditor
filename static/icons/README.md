# PDF İşlemleri Icons ve Favicon Koleksiyonu

Bu klasör, PDF İşlemleri web sitesi için optimize edilmiş tüm icon ve favicon dosyalarını içerir.

## 📱 Desteklenen Platformlar

### Web Browsers
- **Chrome/Edge**: 16x16, 32x32, 48x48, 64x64, 96x96, 128x128, 256x256
- **Firefox**: 16x16, 32x32, 48x48, 64x64, 96x96, 128x128, 256x256
- **Safari**: 16x16, 32x32, 48x48, 64x64, 96x96, 128x128, 256x256

### Apple Devices
- **iPhone**: 57x57, 60x60, 72x72, 76x76, 114x114, 120x120, 144x144, 152x152, 167x167, 180x180, 192x192
- **iPad**: 72x72, 76x76, 144x144, 152x152, 167x167, 180x180, 192x192
- **Mac**: 16x16, 32x32, 48x48, 64x64, 96x96, 128x128, 256x256, 512x512

### Android Devices
- **Chrome**: 192x192, 512x512
- **PWA**: 192x192, 512x512 (maskable)

### Windows
- **Tiles**: 70x70, 150x150, 310x310
- **Favicon**: 16x16, 32x32, 48x48

## 🎨 Dosya Formatları

- **ICO**: Favicon için (16x16, 24x24, 32x32)
- **PNG**: Standart icon formatı (tüm boyutlar)
- **WebP**: Modern web formatı (192x192, 512x512, 1024x1024)
- **SVG**: Safari pinned tab için

## 🔧 Kullanım

### HTML'de
```html
<!-- Favicon -->
<link rel="icon" type="image/x-icon" href="/static/icons/favicon.ico">

<!-- Standard Icons -->
<link rel="icon" type="image/png" sizes="16x16" href="/static/icons/icon-16x16.png">
<link rel="icon" type="image/png" sizes="32x32" href="/static/icons/icon-32x32.png">

<!-- Apple Touch Icons -->
<link rel="apple-touch-icon" sizes="180x180" href="/static/icons/icon-180x180.png">

<!-- Android Chrome Icons -->
<link rel="icon" type="image/png" sizes="192x192" href="/static/icons/android-chrome-192x192.png">

<!-- Microsoft Tiles -->
<meta name="msapplication-TileImage" content="/static/icons/mstile-150x150.png">

<!-- Web App Manifest -->
<link rel="manifest" href="/static/icons/site.webmanifest">
```
